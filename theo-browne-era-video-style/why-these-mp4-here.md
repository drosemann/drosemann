### Why are 15 .mp4 files in my GitHub profile repo?

Short answer: This is my time capsule.

This folder `theo-browne-era-video-style` contains 15 videos from my Tech-Content Phase inspired by Theo Browne. Quick cuts, hot takes, dev rants – my attempt at doing tech content differently after 2000+ gaming videos.

**Why are they HERE and not just on YouTube?**

1.  **Archive, not a content graveyard.** I deleted my old gaming videos once. Not making that mistake again. YouTube compresses, deletes, demonetizes. Git keeps history.
2.  **Proof of work.** These 15 videos are learning-by-doing. Editing, storytelling, audio, pacing. Not perfect, but proof I tried a completely different style.
3.  **Yes, MP4s in Git is bad practice.** I know. Looking at you, Git LFS. This is my profile repo, not production code. It's supposed to be personal.

**Why are 7 videos compressed? Because Microsoft is stingy.**

GitHub = Microsoft. Trillion-dollar company, but still a 25 MB limit for browser uploads and a 100 MB hard limit via Git push. Thanks for that.

7 videos were over the limit and had to be compressed:

| Video | Before | After |
| :--- | ---: | ---: |
| Cloud-Sicherheit | 26.1 MB | 23.8 MB |
| IT-Trends 2024 | 32.3 MB | 23.7 MB |
| TikTok in den USA | 30.6 MB | 23.8 MB |
| Warum Arc | 25.5 MB | 24.1 MB |
| Cloud-Gaming | 41.3 MB | 23.8 MB |
| KI-Agenten | 30.8 MB | 24.2 MB |
| World Labs 3D | 25.9 MB | 23.7 MB |

Slight quality loss, but still watchable. Self-hosting would have been cheaper again – if you don't count your own time.

**Why I'm closing this chapter:**

I'm going back to my **Gaming Video Phase**.

The Theo Browne era taught me a lot about how to explain tech, but gaming is where I started in 2018 with ShadowUnity and where I have the most fun. I want to build where my community actually is.

These videos stay here as a marker. From `Aternos -> KVM` and from `Gaming -> Tech -> Gaming again`.

If you found this folder through my profile: grab some popcorn, these are unlisted and raw.
